# Чаты (`@crm-nordiv/chats`)

Мессенджер компании: личные и групповые беседы, чаты задач. Приложение ставится в CRM без правок
ядра.

- universalIdentifier: `6f0c1c4e-3b0d-4d0c-9d0a-5a6c1f2e7b10`

## Что создаёт приложение

| Объект | Поля |
|---|---|
| `smbConversation` (новый) | вид (личная, групповая, чат записи, обсуждение новости), название, ключ личной беседы, объект и id записи, ключ чата записи, номер последнего сообщения, время последнего сообщения, создатель |
| `smbConversationMember` (новый) | беседа, сотрудник, ключ участника, роль, прочитано до, без звука до |
| `smbConversationMessage` (новый) | беседа, номер, ключ номера, вид, автор, содержимое (JSON редактора), текст, id отправки, ключ отправки, ответ на, изменено, удалено |
| `workspaceMember` | участие в беседах, сообщения (автор), созданные беседы |
| `task` | `smbIsChatEnabled` «Чат задачи», по умолчанию включён |

Записи бесед закрыты от общих API и ролей (`readability` и `writability` = `APPLICATION`):
переписку видят только участники через интерфейс мессенджера.

## Что получается после установки

| Где | Что |
|---|---|
| Сайдбар | пункт «Чаты»: список бесед, переписка, новая личная или групповая беседа |
| Беседа | отправка (Enter, Shift+Enter — новая строка), правка и удаление своих сообщений, «Показать раньше», непрочитанное в списке |
| Карточка задачи | вкладка «Чат»: беседа задачи; кто может прочитать задачу, тот в неё входит |
| Автоматически | автор и исполнитель задачи входят в её чат, когда их двое; выключается полем «Чат задачи» |

Новые сообщения приходят опросом: список раз в 5 секунд, открытая беседа раз в 3 секунды.

Переменная `MESSENGER_ENGINE` («Настройки → Приложения → Чаты») по умолчанию `APP`; менять не нужно.

## Чего приложение не делает

- Мгновенную доставку, «печатает» и признак «в сети»: доставка идёт опросом.
- Уведомления о сообщениях.
- Соисполнителей и наблюдателей в чате задачи.
- Чаты других записей: сделано для задач.
- Упоминания и форматирование: поле ввода — простой текст.

## Установка

С любого компьютера с Node.js 20+, нужен только адрес CRM и ключ API администратора
(«Настройки → API и вебхуки → Создать ключ»). Повторный запуск ставит новую версию:

```bash
npx -y @haiiro/chats install --url https://crm.example.ru --api-key <ключ>
```

Установщик загружает в CRM опубликованный архив этой версии пакета и устанавливает приложение
(как `twenty app:install`), доступ к серверу и его настройки не нужны. Конкретная версия:
`--version 0.0.8`.

Из исходников (для разработки): `node scripts/reinstall.mjs chats --local` в корне репозитория
(нужны `CRM_URL` и `CRM_API_KEY` в `.env`).

## Разработка

```bash
yarn app dev        # следит за src/ и синхронизирует с сервером
yarn test && yarn typecheck && yarn lint
```

Устройство `src/`: `shared/` — общий код (ключи, тело сообщения, нумерация, вид беседы, типы
запросов); `server/` — записи через REST (`records.ts`) и действия мессенджера;
`logic-functions/`; `front/` и `front-components/` — интерфейс; `objects/`, `fields/`, `roles/`,
`page-layouts/`, `navigation-menu-items/`. При смене версии платформы сверять `server/records.ts`
и `front/api.ts`.

Идентификаторы в `src/universal-identifiers.ts` после первой установки не меняются: по ним
приложение обновляется на живых компаниях.
